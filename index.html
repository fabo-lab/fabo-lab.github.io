KW-Analyzer Backup

KW-Analyzer Backup ist ein Werkzeug für den Eigengebrauch. Es sichert die Daten eines lokal laufenden Programms verschlüsselt in das eigene Google Drive des Nutzers (über rclone und restic).

Die App fordert nur die Berechtigung drive.file an: Sie sieht ausschließlich Dateien, die sie selbst angelegt hat. Sie wird nicht öffentlich angeboten.

Datenschutzerklärung

English: KW-Analyzer Backup is a personal, single-user tool. It stores encrypted backups of a locally running program in the user's own Google Drive, using only the drive.file scope. It is not offered to the public. Privacy policy
