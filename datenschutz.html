Datenschutzerklärung – KW-Analyzer Backup

KW-Analyzer Backup wird ausschließlich vom Betreiber selbst für sein eigenes Google-Konto genutzt. Es gibt keine weiteren Nutzer.

Welche Daten die App verarbeitet

  • Die App läuft nur auf dem eigenen Rechner des Nutzers. Es gibt keinen Server des Betreibers, der Daten empfängt.
  • Über die Google-Drive-Berechtigung drive.file legt die App verschlüsselte Backup-Dateien im Google Drive des Nutzers an und liest sie wieder. Andere Dateien in Google Drive sieht sie nicht.
  • Die Google-Anmeldung (OAuth-Token) wird nur lokal und verschlüsselt auf dem Rechner des Nutzers gespeichert. Sie wird an niemanden weitergegeben.
  • Es werden keine Google-Nutzerdaten verkauft, für Werbung genutzt oder an Dritte übermittelt.

Widerruf

Der Zugriff lässt sich jederzeit unter myaccount.google.com/connections widerrufen.

Diese Webseite

Diese Seite wird über GitHub Pages bereitgestellt. GitHub verarbeitet dabei technisch notwendige Daten wie die IP-Adresse der Besucher; siehe die Datenschutzerklärung von GitHub. Der Betreiber selbst erhebt auf dieser Seite keine Daten und setzt keine Cookies.

Privacy policy (English)

KW-Analyzer Backup is used only by its operator, for the operator's own Google account. The app runs locally; there is no server of the operator. With the drive.file scope it creates and reads encrypted backup files in the user's own Google Drive and cannot see other files. The OAuth token is stored only locally and encrypted. No Google user data is sold, used for advertising or shared with third parties. Access can be revoked at any time at myaccount.google.com/connections. This page is hosted on GitHub Pages; GitHub processes technically necessary data such as visitors' IP addresses.
